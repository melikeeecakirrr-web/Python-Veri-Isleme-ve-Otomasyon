# Python ile Veri İşleme ve Otomasyon Projesi

## Proje Özeti

Bu proje, Python kullanılarak veri işleme, analiz ve otomasyon süreçlerini desteklemek amacıyla geliştirilmiştir. İş verilerinin düzenlenmesi, analiz edilmesi ve raporlanması süreçlerinde otomasyon yaklaşımı benimsenmiştir.

## Proje İçeriği

Projede örnek satış ve performans verileri kullanılarak;

* verilerin temizlenmesi,
* düzenlenmesi,
* kategorize edilmesi,
* temel analizlerinin yapılması,
* otomatik rapor oluşturulması
  çalışmaları gerçekleştirilmiştir.

## Kullanılan Teknolojiler

* Python
* Pandas
* Excel / CSV Veri İşleme
* Temel Veri Analizi Teknikleri

## Veri Seti

Projede örnek iş verileri (satış, departman performansı ve operasyonel KPI verileri) kullanılmıştır. Veri seti; analiz, sınıflandırma ve raporlama süreçlerini simüle etmek amacıyla oluşturulmuştur.

## Kazanımlar

Bu çalışma kapsamında:

* veri analizi yaklaşımı geliştirildi,
* otomasyon odaklı düşünme becerisi kazanıldı,
* raporlama süreçleri desteklendi,
* iş süreçlerinin verimliliğini artırmaya yönelik teknik çözümler üretildi.
